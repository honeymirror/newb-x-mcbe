# Newb X Legacy - RenderDragonShaderLoader Variant

This repository is an unofficial RenderDragonShaderLoader compatibility variant of
[Newb X Legacy](https://github.com/devendrn/newb-x-mcbe) `v16.56`.

The default branch is a complete, directly importable shader pack. GitHub Releases are not
required.

## Download and Install

1. Install RenderDragonShaderLoader `0.2.0-beta` or later.
2. Click **Code > Download ZIP** on this repository.
3. Import the downloaded ZIP into RenderDragonShaderLoader.
4. Select the `Default` configuration and apply it.

The pack contains source metadata, localization, custom parameters, and precompiled Windows
material outputs. A normal installation does not need a separate compilation step.

## Included Content

- NewBx `v16.56` shader source adapted for Minecraft Bedrock `1.26.51`.
- 13 precompiled materials.
- 87 custom parameters.
- 8 cloud, fog, and chunk-animation variants.
